# Mockups

**View them here:** https://claude.ai/artifact/WG7JfdUvy8fdtykjd8v3sE (a private design canvas; share it from the page's Share menu if others need to see it).

14 artboards, monochrome with translucent glass, using Alte Haas Grotesk from `packages/ui`:

| Artboard | What it shows |
|---|---|
| **The notch** (interactive) | Idle with ears, peek, open (Now / Approvals / Shelf / Ask tabs), live job, recording. Click the state bar or hover the notch |
| **Identity** | The 11 monogram tiles with each agent's signature pattern, colour tokens, type scale, core components (Ask bar, approval card, source chips, model badges, activity row) |
| **iPhone** | Lock screen with Dynamic Island + Live Activity, Today tab, Approvals queue |
| **leo** | Today: morning brief, timeline, prep card, approvals, activity |
| **bolton** | Search-first home: query understanding, cited answer, ranked results, "about this file" |
| **marc** | Inbox lanes with reasons, reader, a draft in your voice with approve/edit, person strip |
| **william** | Editor with suggestion mode, "sounds like you" score, voice traits |
| **james** | Browser with vertical tabs + a cited research report and sources |
| **johnny** | Terminal with an AI command proposal and dry run, plus Tune (a spec diff for Marc with before/after) |
| **george** | Cash, burn, runway tiles, monochrome forecast chart (base vs scenario), upcoming, costs |
| **conner** | Pipeline board, lead detection from email, nudges, red-team note |
| **robert** | Canvas with an on-brand social graphic, variants, critique, brand kit |
| **cole** | Transcript-first editor: struck-through fillers and pauses, timeline, auto-clips |
| **harris** | "10 minutes today": path session, flashcard, speaking drill |

Numbers in square brackets (`[CASH]`, `[PRICE]`) are placeholders, not real figures. The product names in James's report are generic on purpose.

`source/` holds the artboard sources (`.dc.html`) for reference, useful when translating screens into SwiftUI. They render only inside the design canvas.
